# FAQ-003 监控页无数据（未关联 Prometheus）

- **分类**：监控与数据源
- **涉及组件**：集群监控大盘 / Prometheus 数据源

## 现象

进入集群「监控」页后看不到有效指标数据。常见形态：

1. 页面展示 Prometheus 引导页（「关联已有 Prometheus 实例」），大盘未加载
2. 能进入监控视图，但各面板无数据

> 若 Prometheus 已关联，仅 etcd 等个别面板为空，请看 [FAQ-001](./etcd-metrics-empty.md)。

## 根因

该集群尚未创建或未关联可用的 **Prometheus 数据源**（产品内类型为「告警」、数据来源为 `Prometheus`，并通过「关联集群」绑定到目标集群）。

监控大盘依赖该数据源做 PromQL 查询；未绑定则无法拉取指标。

## 验证方式

1. 打开顶部菜单 **数据源**（路径 `/datasource`）
2. 按目标集群筛选，确认是否存在：
   - 类型：告警
   - 数据来源：Prometheus
   - 关联集群：当前集群
3. 或在该集群监控页查看：若仍停留在引导页、点击「关联已有 Prometheus 实例」时无可选实例，说明尚未创建可用数据源

## 解决方案

任选其一即可。

### 方案 A：在监控页关联已有实例（推荐，已有数据源时）

1. 进入目标集群 → **监控**
2. 点击 **关联已有 Prometheus 实例**
3. 在弹窗中选择已有 Prometheus 实例 → **确认**
4. 若列表为空，点击提示中的 **新建实例**，跳转数据源页按方案 B 创建后再回来关联

关联成功后会在当前集群下写入一条 Prometheus 数据源（默认数据源），刷新监控页即可。

### 方案 B：在数据源页新建并关联集群

1. 打开顶部菜单 **数据源** → **添加数据源**
2. 填写基础信息：
   - **名称**：自定义，如 `prometheus`
   - **类型**：告警
   - **数据来源**：Prometheus
   - **来源类别**：
     - 集群内 Prometheus：选 **Kubernetes**，并填写 **关联集群**、命名空间与 Service
     - 集群外可达地址：选 **外部集群**，填写 Prometheus URL
3. 按需勾选 **设为默认**（监控页优先使用默认告警数据源）
4. 保存后回到目标集群 **监控** 页刷新；若仍提示关联，再执行方案 A 选中刚创建的实例

## 备注 / 风险

- 「创建 Prometheus 数据库」在产品中对应 **添加 Prometheus 数据源（实例）**，不是业务库建表
- 集群内需已部署可查询的 Prometheus（或兼容的 metrics 服务）；仅创建数据源记录、后端不可达，面板仍会无数据
- 同一集群同类型默认数据源通常只能有一个；冲突时先取消旧默认再设新默认
- 子集群场景下，监控数据源可能挂在主集群名下，列表展示以归属集群为准
